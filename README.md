# Social Media Automation

Collaborative college project for social media automation.

## Getting started

```bash
git clone https://github.com/devgeektech/Socailmedia_automtion.git
cd Socailmedia_automtion
```

## Contributing

1. Clone the repo
2. Create a branch: `git checkout -b your-feature`
3. Commit and push your changes
4. Open a pull request (or push if you have write access)
